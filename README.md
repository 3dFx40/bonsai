# Bonsai

בונסאי חי ב־Godot 4.7.2 ו־GDScript, גרסה 0.3.2 לבדיקה אישית. בוחרים צמח ואדנית, ונותנים לעץ לגדול בזמן אמיתי מואץ; השקיה, דישון, גיזום ועיצוב ענפים משנים את בריאותו ואת המבנה שלו. מדריך פתיחה, המלצות טיפול ויומן מלווים את העץ. אין רמות, מטבעות, פרסומות או רכישות אמיתיות.

## פתיחה והרצה

פתחו `project.godot` ב־Godot 4.7.2 stable ולחצו F6 בסצנה הראשית או F5 להרצת הפרויקט. גרסה ניידת מקומית, אם הורדה בזמן הפיתוח, נמצאת ב־`.tools/godot/` ואינה חלק מ־Git.

ב־Windows אפשר להריץ מהתיקייה:

```powershell
.\scripts\run.ps1          # המשחק
.\scripts\run.ps1 -Editor  # עורך Godot
.\scripts\run.ps1 -Test    # בדיקות לוגיקה, שמירה, מגע ופתיחה מחדש
.\scripts\run.ps1 -Capture # צילום דרך הרינדור האמיתי ל-builds/studio.png
```

אפשר למסור `-Godot C:\path\godot.exe` למנוע חיצוני. הסקריפט שומר נתוני פיתוח תחת `.tools/userdata/` בתוך הפרויקט. פתיחה רגילה בעורך ושימוש בקובץ EXE משתמשים בתיקיית `user://` הרגילה של Godot, ולכן זה עץ נפרד.

תוצרי הבנייה המקומיים נמצאים ב־`builds/Bonsai-debug.apk` וב־`builds/Bonsai.exe`. התיקייה אינה נשמרת ב־Git. ה־APK מיועד לבדיקה, וה־EXE הוא Release ללא לוח פיתוח.

Windows נבדק בהרצה. ה־APK המעודכן נבנה וחתימתו אומתה. גרסה קודמת הותקנה באמולטור, אך בדיקה חזותית מלאה ב־Android נותרה פתוחה בגלל תקלות מערכת באמולטור; לא נבדק טלפון פיזי. ראו `docs/VALIDATION.md` לפרטים.

## שליטה

כפתור × בפינה הימנית העליונה סוגר את האפליקציה ושומר את העץ. הוא זמין גם במסך היצירה ובהגדרות. כפתור **צור עץ חדש** מופיע ראשון בהגדרות, ומתחתיו מספר הגרסה.

בחירת שפה נמצאת ב־**הגדרות → שפה**: עברית / English. ההחלפה מיידית, כולל מידע דינמי וכלי הפיתוח, והבחירה נשמרת. בעברית הממשק פועל מימין לשמאל. בשמירה ישנה ללא בחירת שפה, ברירת המחדל נגזרת משפת המכשיר: עברית במכשיר עברי, ואנגלית בשאר המכשירים.

בפתיחה הראשונה יוצרים עץ בשני שלבים: בוחרים פיקוס, פורטולקריה או אולמוס סיני, ואז אחת מארבע אדניות — קרמיקה בצבע צפחה, טרקוטה עגולה, קרמיקה בצבע שנהב או קרמיקה כחולה. התצוגה התלת־ממדית משתנה עם הבחירה. אפשר להוסיף שם אישי, ורק בלחיצה על **מתחילים לגדל** נכנסים למשחק ונשמר העץ. לכל צמח מראה ופרמטרי צמיחה משלו.

המדריך מופיע אחרי יצירת העץ הראשון, ואפשר לפתוח אותו שוב מההגדרות. באותו מסך אפשר לבחור שם לעץ, קול ואיכות, ולייצא או לשחזר גיבוי. **הגדרות → צור עץ חדש** מאפשר ליצור עץ נוסף; ביטול מחזיר לעץ הקודם. עצים קודמים נשמרים בנתונים, אך עדיין אין ממשק למעבר ביניהם. שמירה קיימת נפתחת ישירות למשחק.

גרירה באצבע או בעכבר מסובבת את המצלמה. צביטה בשתי אצבעות או גלגלת משנות מרחק. הממשק נבנה לרוחב עיצוב של 720 ובגובה 1280, בתצוגה לאורך.

| כלי | פעולה |
|---|---|
| Observe | נגיעה בענף בוחרת אותו; לחיצה ארוכה ושחרור מציגים גם גיל |
| Water | לבחור כלי וללחוץ Water the soil |
| Feed | לבחור כלי וללחוץ Add a small dose |
| Prune | לבחור ענף ואז ללחוץ ענף שלם או מקטע מהענף; במצב מקטע אפשר להשאיר 20–90% מאורך הענף. האזור הענברי מציג מה יוסר |
| Undo | מבטל גיזום במשך 15 שניות; טיפול נוסף מבטל את האפשרות |
| View | מסתיר את ממשק הטיפול ומסובב את העץ לצפייה; Back to care מחזיר אותו |
| Journal | שמירת דיוקן והשוואתו לעץ הנוכחי; מוצגים גם הטיפולים האחרונים |
| Dev | עצירה, קפיצות זמן, מים/מזון/אור, פגיעה/שיקום, צמיחה, גרף ואיפוס מאושר בלחיצה נוספת |

צלילים מופעלים לפי בחירה. כפתור האיכות מחליף Low / Medium / High. Low מגביל ל־30 פריימים בשנייה ומכבה צל ו־MSAA; שאר המצבים מוגבלים ל־60. כלי הפיתוח זמינים רק בבניית Debug וגם רק כאשר `bonsai/developer_tools=true`.

## זמן וטיפול

ברירת המחדל: שעה אמיתית = יום ביולוגי. משנים ב־Project Settings תחת `bonsai/real_seconds_per_day` לפני יצירת שמירה חדשה, או בהגדרה השמורה. שינוי קצב בשמירה קיימת דורש עריכת ההגדרה במפורש כדי לא לשנות בדיעבד את קצבו של עץ קיים.

הסימולציה משלימה צעדי רבע יום; בברירת המחדל נראה עדכון צמיחה כל 15 דקות. מים ודשן מתעדכנים מיד. קפיצות Dev הן זמן ביולוגי, ולכן `+1 day` מציג שינוי בלי לחכות שעה. יובש, עודף מים, עודף דשן ואור חלש פוגעים בצימוח בהדרגה. צמיחה היא הארכה, התעבות, עלים וניצנים חדשים; אין הגדלה אחידה של מודל.

בהיעדרות ארוכה עוברים לכל היותר 28 ימים ביולוגיים מפורטים, ולאחריהם תרדמת מגינה. כל הזמן נספר בגיל, אך התרדמת עוצרת נזק וצימוח. העץ נשאר בר־שיקום; אין מוות סופי בגרסה זו. אלה ערכי ניסוי למשחק, לא הוראות לטיפול בצמח אמיתי.

## שמירה

שמירת JSON בגרסה 2 מתבצעת אחרי טיפול, אחת ל־20 שניות, בהשהיה וביציאה מסודרת. שמירות גרסה 1 משודרגות אוטומטית. `grove.json.bak` הוא הדור התקין הקודם. במקרה של קובץ פגום נטען גיבוי; גרסה חדשה יותר לא נדרסת. בשמירה יש מערך עצים כבר עכשיו, אף שממשק המשחק מציג עץ אחד.

יומן העץ שומר עד 256 טיפולים ו־12 דיוקנאות של מבנה העץ: הראשון נשמר תמיד, יחד עם 11 האחרונים. דיוקן אוטומטי נוסף לכל היותר פעם ביום אמיתי, בשמירה הבאה. השוואה מציגה את העבר בלי לשנות את העץ החי.

**הגדרות → ייצוא גיבוי** שומר קובץ JSON מחוץ לאפליקציה. שחזור דורש אישור ומחליף את העץ וההגדרות. המצב שלפני השחזור נשמר בנפרד ב־`grove.json.before-restore`; שמירה אוטומטית אינה מוחקת אותו. כפתור ההחזרה בהגדרות מאפשר לשחזר גם אותו. ב־Android 10 ומעלה נעשה שימוש בבוחר קבצים של המערכת; הבחירה והשיתוף של הקובץ על מכשיר פיזי עדיין דורשים בדיקה. שמירה מוגנת עקב גרסה לא נתמכת או קבצים לא קריאים נשארת מוגנת גם מפני שחזור.

נתיב ברירת המחדל ב־Windows: `%APPDATA%/Godot/app_userdata/Bonsai/grove.json`. בהפעלה דרך הסקריפט: `.tools/userdata/Godot/app_userdata/Bonsai/grove.json`. ב־Android הנתונים נשמרים באחסון הפרטי של האפליקציה.

## Android

ה־preset בשם `Android` מוגדר ל־arm64 וגם x86_64 עבור אמולטור. מצב הרינדור הוא Compatibility, הכיוון לאורך, ואין הרשאת רשת או אחסון חיצוני.

1. להתקין תבניות Export התואמות **בדיוק** ל־Godot 4.7.2.
2. להגדיר ב־Editor Settings → Export → Android את נתיבי Java SDK ו־Android SDK. JDK 17 מומלץ בתיעוד; כאן נעשה שימוש ב־JBR הקיים של Android Studio. SDK 36 וכלי בנייה 36.0.0 שימשו לבנייה המקומית.
3. לבחור Project → Export → Android ולייצא APK עם Debug. לחלופין:

```powershell
godot --headless --path . --export-debug Android builds/Bonsai-debug.apk
adb install -r builds/Bonsai-debug.apk
adb shell am start -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -p org.bonsai.verticalslice
```

לבניית AAB: להתקין Android Build Template מתוך תפריט Project, להפעיל Gradle Build ב־preset, לבחור AAB ולספק מפתח Release משלכם. אין מפתח פרסום או פרטי חנות בריפו. תהליך AAB ופרסום לחנות לא אומתו. ל־Release כלי Dev כבויים גם אם ההגדרה נשארת פעילה.

להפקת Windows: `godot --headless --path . --export-release "Windows Desktop" builds/Bonsai.exe`.

עם המנוע והתבניות המקומיים אפשר להשתמש ב־`scripts/build.ps1 -Target Android`, או `scripts/build.ps1 -Target 'Windows Desktop' -Release`.

מקור: [ייצוא Android בתיעוד Godot](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html). רשימת בדיקות ומגבלות נמצאת ב־`docs/VALIDATION.md`.

## השלב הבא

בדיקת שימוש ממושכת על טלפון פיזי, כיוון קצב הטיפול והצמיחה, והחלפת נכסים לפי `ASSET_REQUIREMENTS.md`. הגרפיקה והקולות עדיין זמניים. עיצוב הענפים משנה את כיוונם מיד; אין סימולציית חוטים או החלמה מכיפוף. אין אוסף, ענן או מסחר. הגרסה מוכנה להתקנה ולבדיקה אישית, וטרם אומתה להפצה בחנות.
