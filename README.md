# Bonsai

פרוסת משחק של בונסאי חי, ב־Godot 4.7.2 ו־GDScript. הפיקוס גדל בזמן אמיתי מואץ; הטיפול והגיזום אמורים לעצב את אותו עץ לאורך זמן.

## פתיחה והרצה

פתחו `project.godot` ב־Godot 4.7.2 stable ולחצו F6 בסצנה הראשית או F5 להרצת הפרויקט. גרסה ניידת מקומית, אם הורדה בזמן הפיתוח, נמצאת ב־`.tools/godot/` ואינה חלק מ־Git.

## שליטה

גרירה באצבע או בעכבר מסובבת את המצלמה. צביטה בשתי אצבעות או גלגלת משנות מרחק. הממשק נבנה לרוחב עיצוב של 720 ובגובה 1280, בתצוגה לאורך.

## קבצים חשובים

- `scenes/main.tscn` — נקודת הכניסה.
- `scripts/` — קוד, לפי מערכות.
- `resources/species/` — פרמטרים של מינים.
- `assets/` — מודלים, טקסטורות וקול, כשיתווספו.
- `tests/` — בדיקות הסימולציה וההתמדה.
- `ARCHITECTURE.md` — החלטות וגבולות בין מערכות.
- `PROJECT_PLAN.md` — התקדמות ואימות אבני דרך.

## Android

ייצוא יוגדר בשלב 8. נדרשים תבניות ייצוא התואמות למנוע, JDK ו־Android SDK; אין תלות Android בלוגיקת העץ.

## השלב הבא

להחליף את העץ הזמני בגרף פרוצדורלי ולבדוק צמיחה וגיזום לפני הוספת תוכן.
