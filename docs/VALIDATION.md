# אימות הפרוסה

נבדק ב־Godot 4.7.2 stable, ב־Windows. אין לדווח על בדיקת טלפון פיזי: לא חובר טלפון בזמן העבודה.

## בדיקות אוטומטיות שעברו

הפקודה: `scripts/run.ps1 -Test`.

| בדיקה | מה אומת |
|---|---|
| `tree_test.gd` | 35 ענפים ו־192 עלים בתחילה, הסרת תת־עץ, הגנה על הגזע והמרת כל שדות העץ |
| `simulation_test.gd` | הארכה, התעבות, עלים, צריכת מים, השקיה, יובש, עודפי מים ודשן, ניצנים אחרי גיזום ואור חלש |
| שעון באותה חבילה | שקילות צעדים מקוונים לדילוג, שעה / 12 שעות / יומיים / שבוע, עשר שנות היעדרות ב־112 צעדים לכל היותר, שעון שחזר אחורה |
| `save_test.gd` | שני עצים, סבב שמירה וטעינה, החלפה, גיבוי, שחזור מקובץ פגום, מעגל בגרף, עלה פגום וחסימת דריסת גרסה עתידית |
| `input_test.gd` | אירועי ScreenTouch ו־ScreenDrag: סיבוב, צביטה, בחירת ענף, כלי מים, השקיה, חסימת זליגת UI למצלמה והשהיה/חזרה |
| `localization_test.gd` | בחירת עברית ואנגלית, החלפת RTL/LTR, תרגום מידע דינמי ושגיאות עם פרמטרים, כלי פיתוח, תאימות שמירות ישנות ודחיית שפה לא נתמכת |
| `relaunch_test.gd` | טעינת סצנת המשחק משמירה ישנה, אותו מזהה ואותו גיזום, שחזור קול ואיכות, שמירת בחירת עברית, חישוב שעה בחוץ ואי־ספירה כפולה בפתיחה נוספת |
| `--smoke` | חיבור הבקר למים, דשן, גיזום, Undo, האצת זמן ולוח הגרף |

בדיקות המגע מזריקות אירועי מגע למנוע ומשתמשות במיקום האמיתי של הכפתורים. הן אינן מחליפות בדיקת אחיזה ואצבעות על טלפון.

## הרצה וייצוא

- הסצנה רונדרה ב־Compatibility דרך ANGLE על Intel HD Graphics 620. צילום אמיתי נשמר ב־`builds/studio.png`.
- Windows Release נבנה ל־EXE עם PCK מוטמע, הורץ בנפרד עם `--headless --quit-after 10` וחזר בקוד 0 וללא שגיאות בלוג.
- APK Debug נבנה ונחתם במפתח בדיקה, עם `arm64-v8a` ו־`x86_64`. ה־APK אומת על ידי כלי החתימה. גודל הבנייה כ־57 MB.
- לפי `aapt`: חבילת `org.bonsai.verticalslice`, גרסה `0.1.0`, minimum SDK 24, target SDK 36.
- גרסת ה־APK שלפני עדכון השפה הותקנה באמולטור API 36 והגיעה ללולאת המשחק ולקובץ שמירה פרטי. אימות חזותי מלא ואינטראקציה על Android **לא הושלמו**: מערכת האמולטור מציגה System ANR. גם אמולטור נקי, שנוצר בתוך הפרויקט, הציג ANR בשירותי הטלפון ו־Google לפני שהמשחק הותקן בו. האמולטורים הופסקו בתום הבדיקה. אין להסיק מכך שה־APK נבדק במלואו על מכשיר.

## תקלות שנמצאו ותוקנו

- שגיאת טיפוסים בקלט GDScript תוקנה לפני מעבר לגרף העץ.
- טבעות הענפים יצרו חיבורים שבורים; הוחלפו בטבעות משותפות וכיוון פאות תקין.
- כיוון ממשק אנגלי הושפע משפת המערכת בעברית; כעת כיוון הממשק נקבע לפי השפה שנבחרה במשחק: LTR באנגלית ו־RTL בעברית.
- הפאנל התחתון נחתך בתצוגה לאורך; נוספה לו מסגרת גובה מתאימה.
- ייצוא Android דרש ETC2/ASTC; ההגדרה נוספה.
- מגבלת uniforms הופיעה ב־SwiftShader של האמולטור; תקציב אורות OpenGL צומצם ל־2 לאובייקט ו־8 לסצנה. הסצנה משתמשת בפועל באור כיווני אחד. בהרצת host העדכנית לא הופיעו שגיאות shader אלו.
- האמולטור הקיים סבל מ־System ANR ואתחולי שירותים. נוצר אמולטור נקי בתיקיית `.tools/avd`, וגם בו הופיעו תקלות מערכת לפני התקנת המשחק. ההגדרות והנתונים השמורים של האמולטור המקורי לא שונו: הוא הופעל ב־read-only ללא שמירת snapshot.

## מגבלות ידועות

- האמנות והצלילים זמניים. אין טענה לריאליזם סופי או למדידת ביצועים על טלפון.
- AAB, חתימת פרסום, Google Play, iOS ו־Web לא נבנו או נבדקו.
- הגיזום מסיר ענף בבסיסו; אין חיתוך במיקום שרירותי לאורך ענף.
- בחירה משתמשת בקרבה לקו המוקרן, ולכן ענפים חופפים עלולים לדרוש סיבוב קטן.
- עד 180 ענפים, 18 עלים לענף ו־256 אירועי גיזום. אין תצוגת אוסף.
- תרדמת אחרי 28 ימים ביולוגיים היא כלל משחק מכוון; אין סימולציה מפורטת של כל יום בהיעדרות ארוכה.
- כיבוי כפוי עלול לאבד עד 20 שניות. אין סנכרון ענן, הצפנה או מנגנון נגד שינוי שעון.

## מעבר למכשיר פיזי

עדכון השפה נבדק ב־29 בספטמבר 2026: כל חבילת `scripts/run.ps1 -Test` עברה, כולל החלפת שפה ושימורה בפתיחה מחדש. צילומי הרינדור `builds/studio-he.png`, `builds/studio-en.png` ו־`builds/studio-he-debug.png` נבדקו חזותית ב־Windows. העברית מוצגת כראוי והממשק מתהפך לפי השפה.

ה־EXE וה־APK נבנו מחדש עם עדכון השפה. ה־EXE הופעל עם עברית במצב בדיקה ללא כתיבה לשמירה רגילה, והסתיים בקוד 0 ללא שגיאות. חתימת ה־APK אומתה שוב באמצעות `apksigner verify`; קטלוג העברית ונתוני Unicode נמצאים בתוך ה־APK. הבנייה העדכנית לא הותקנה מחדש באמולטור ולא נבדקה על טלפון פיזי.

להתקין APK, לבדוק צביטה וסיבוב ביד אחת/שתיים, בחירה בענפים חופפים, כפתורים ליד אזורי מערכת, מעבר לרקע וחזרה, סגירה כפויה אחרי טיפול, ומצב Low לאורך 15 דקות. להשוות צילום וגרף אחרי גיזום ולחזור לאחר שעה ויום. למדוד זמן פריים וצריכת סוללה לפני העלאת תקרות הגאומטריה.
